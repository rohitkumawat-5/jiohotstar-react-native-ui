# JioHotstar Home Screen UI in React Native

A JioHotstar-inspired OTT home screen UI recreated using React Native.

## Features

- JioHotstar-inspired home screen
- Featured content banner
- Movie and show cards
- Horizontal content sections
- Bottom navigation
- Dark OTT-style interface
- Responsive mobile UI

## Tech Stack

- React Native
- JavaScript

## Installation

npm install

## Run the project

npx react-native start

npx react-native run-android

## Disclaimer

This is an independent educational UI recreation inspired by the JioHotstar interface. It is not an official JioHotstar application and is not affiliated with JioHotstar or its owners.
